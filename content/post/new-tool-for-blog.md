\#\# 为什么想搞这个工具？
一开始我不想学什么 Markdown 语法，觉得敲星号井号太麻烦了。我就想：\*\*能不能像用 Word 一样，点个按钮就能加粗，然后再推送到 GitHub 上？\*\*
后来我决定写个本地网页工具（HTML），因为我是个小白，不想搞太复杂的后端。
\#\# 折腾之路
我们一开始直接手写代码，用 GitHub 的 API 把写好的内容推送到我博客的 \`content/post\` 文件夹里。后来我觉得每次都要填 GitHub 密钥太烦了，而且 UI 太丑了，于是做了以下升级：
\* \*\*极简风格\*\*：界面大改版。
\* \*\*毛玻璃质感\*\*：背景加了模糊效果。
\* \*\*动画反馈\*\*：按钮点击带点过渡动画。
\#\# AI 降临
再后来，因为我实在不会写文章，我直接把智谱的 AI 接口接进去了。
\> 现在的情况是：我只要在网页里输入大白话，点一下“AI 润色排版”，智谱就会自动帮我用 Markdown 语法把文章排版好。
然后我再点一下“发布到博客”，代码就会自动完成剩下的工作：
1\. 加上标题、分类、标签。
2\. 推送到 GitHub 仓库。
3\. GitHub Actions 自动部署。
4\. 博客更新完成！

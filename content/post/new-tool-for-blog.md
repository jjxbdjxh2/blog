# 我用一个本地 HTML 页面，把发博客变成了“点两下鼠标”的事

## 起因：我不想学 Markdown

一开始，我只是想给自己的 Hugo 博客找个方便发文章的工具。

那时候我对 Markdown 语法挺抵触的。写个加粗要敲星号，写个标题要敲井号，想想就麻烦。我当时的想法很简单：能不能像用 Word 一样，选中文字，点个按钮就能加粗，然后一键推送到 GitHub 上？

后来我决定写一个本地网页工具。原因也很朴素：我是个小白，不想搞太复杂的后端。于是最开始的版本就是直接手写 HTML，用 GitHub 的 API 把写好的内容推送到博客的 `content/post` 文件夹里。

能用，但很原始。

## 第一次改造：把密钥写死，把界面做顺眼

最初每次发文章都要填 GitHub 密钥，填得我有点烦。再加上界面确实不太好看，我就动手改了一版。

这一版的目标很明确：

- 把密钥直接写死在代码里，省得每次重复输入；
- 界面改成极简风格；
- 背景做成毛玻璃质感；
- 按钮加上一点动画。

于是它从一个“能用的脚本页面”，变成了一个至少我自己愿意打开的小工具。

## 第二次改造：把智谱 AI 接进来

再后来，问题变成了：我实在不会写文章。

于是我又把智谱的 AI 接口接了进来，用的是 `glm-4-flash` 模型。现在整个流程变成了这样：

1. 我在网页里输入大白话；
2. 点一下“AI 润色排版”；
3. 智谱自动帮我把文章用 Markdown 语法排版好；
4. 我再点一下“发布到博客”；
5. 代码自动给文章加上标题、分类、标签，推送到 GitHub 仓库；
6. GitHub Actions 自动部署完成，博客就更新了。

整个过程不需要我手动碰 Markdown，也不需要打开编辑器改 front matter。写大白话，点两下鼠标，文章就发出去了。

## 一点小插曲：硬核诅咒

为了防止别人偷我的 API，我还在代码里加了一句“盗我API死全家”的硬核诅咒。

不过好在这个模型是免费的，随便刷。所以这句诅咒更多是情绪表达，实际防护效果有限。真要认真做，还是得把密钥放到后端或者环境变量里，不能长期写死在前端代码里。

## 现在的状态

现在这个工具对我来说已经非常好用了：

- 打开网页；
- 写写大白话；
- 点“AI 润色排版”；
- 点“发布到博客”。

等 GitHub Actions 跑完，博客就更新了。

从“不想学 Markdown”开始，到最后做出一个带毛玻璃 UI、按钮动画、AI 排版和 GitHub API 推送的本地小工具，整个过程其实就是在不断偷懒的过程中，把工具一步步打磨成了自己顺手的样子。
